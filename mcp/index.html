Let your agent kill the idea.

The Kill My Idea MCP server gives Claude, ChatGPT, Cursor, Codex and any other AI agent one honest tool: judge a startup idea. KILL IT, FIX IT or SHIP IT, a 0-100 score, the best signal and the biggest risk. In about a second.

Endpoint · Streamable HTTP

__SITE_URL__/api/mcp

No auth header. No session. Stateless JSON-RPC over POST.

Tools

judge_idea

Judges a startup or side-project idea. Returns the verdict, a 0-100 score, the best signal, the biggest risk and eight 0-100 sub-scores, each with its weight.

ArgumentTypeWhat it does
ideastring, 20-5000 charsRequired. Who it is for, what it does, how it makes money or spreads. More detail, better verdict.
goal"money" | "open_source" | "fun"Default money. open_source swaps Money for Adoption; fun swaps Real problem and Money for Immediate appeal and Fun.
do_not_archivebooleanDefault false. Set true for confidential ideas: the text is not stored.

get_stats

How many ideas Kill My Idea has analyzed and how many were killed, fixed or shipped. No arguments.

Build it into your own agent

Raw HTTP

curl -s __SITE_URL__/api/mcp \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{
        "name":"judge_idea",
        "arguments":{"idea":"A Slack bot that turns standups into a weekly changelog for clients.","goal":"money"}}}'

TypeScript MCP SDK

import { Client } from '@modelcontextprotocol/sdk/client/index.js'
import { StreamableHTTPClientTransport } from '@modelcontextprotocol/sdk/client/streamableHttp.js'

const client = new Client({ name: 'my-agent', version: '1.0.0' })
await client.connect(new StreamableHTTPClientTransport(new URL('__SITE_URL__/api/mcp')))

const { structuredContent } = await client.callTool({
  name: 'judge_idea',
  arguments: { idea: 'A Slack bot that turns standups into a weekly changelog for clients.' },
})

How Jev decides

No chatbot opinion. Jev by TypeSafe AI answers ten fixed questions in parallel with calibrated probabilities: eight indie-hacker questions scored 0-4, the category, and whether the idea is understandable at all.

  • Each answer × 25 → 0-100. The score is the weighted average. Real problem and Money count twice.
  • KILL IT below 50 · FIX IT 50-64 · SHIP IT 65+.
  • The same idea gets the same rubric every time. The code is open source.

FAQ

Is it really free?
Yes. No API key, no account, no OAuth. Please don't hammer it: it is a side project.
Which clients work?
Anything that supports remote MCP servers over Streamable HTTP. Older clients can bridge with npx mcp-remote.
Are my ideas stored?
Archived anonymously for product analytics, with no IP address and no identifiers. Pass do_not_archive: true and the text is not stored. Calls are counted (tool name, client name, user agent), never their arguments. Details in the privacy policy.
Can I trust the verdict?
It is a fast, consistent first filter, not market research. Use the biggest risk to decide what to test next.
